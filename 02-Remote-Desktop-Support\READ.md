# Remote Desktop Support

## Overview

This lab demonstrates a basic remote support workflow using Remote Desktop Protocol (RDP).

## Objective

Practice configuring and using Remote Desktop to remotely access a Windows Server and perform administrative tasks.

## Lab Environment

- Windows Server
- Active Directory Domain Services
- Domain: mbulelo.local
- Server: AD-SERVER
- Remote Desktop Protocol (RDP)
- VirtualBox

## Skills Demonstrated

- Remote Desktop configuration
- Remote system access
- Windows Server administration
- Remote troubleshooting
- Basic helpdesk support workflow

## Result

Successfully established a remote desktop session to the Windows Server and performed administrative tasks remotely.
