# Active Directory Setup

## Overview

Built a Windows Server Active Directory lab environment using VirtualBox.

## Lab Environment

- Windows Server
- Active Directory Domain Services (AD DS)
- Active Directory Domain: `mbulelo.local`
- Server Name: `AD-SERVER`
- PowerShell
- Oracle VirtualBox

## Objectives

- Install and configure Active Directory Domain Services
- Create the `mbulelo.local` domain
- Configure DNS for the domain
- Create and manage domain users
- Build a foundation for simulated IT helpdesk scenarios

## Skills Demonstrated

- Windows Server administration
- Active Directory fundamentals
- DNS configuration
- PowerShell
- Virtual machine administration
- Basic troubleshooting
